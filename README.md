# Smart Expense Tracker 💰

A native Android app built with **Kotlin, Android Studio, and Jetpack Compose** for managing personal finances.

## Features
- **Dashboard:** View balance, spending overview, and recent transactions.
- **Transactions:** Add, edit, view, and delete income and expenses.
- **Budget:** Set budgets and track spending.
- **Reports:** Generate and share financial reports.
- **Analysis:** Visualize spending patterns and categories.

## Project Structure
- `data/` — Models and data access.
- `viewmodel/` — Screen logic and UI state.
- `ui/` — Screens and reusable components.
- `ui/navigation/` — Navigation between screens.
- `ui/theme/` — App colors and styling.
